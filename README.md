## Atividade: Identidade Visual - Itaú

Este projeto consiste no desenvolvimento e documentação da **identidade visual do Banco Itaú** utilizando o Figma. O guia de estilos (Design System básico) estabelecido nesta atividade serve como base padronizada para a interface de todos os futuros trabalhos e projetos integradores do curso.

## 🎯 Objetivo

Garantir a consistência visual, acessibilidade e padronização dos componentes de interface (UI) baseados na marca Itaú, aplicando conceitos práticos de cores, tipografia, escala de fontes e testes de contraste.

---

## 🎨 Guia de Estilos (Style Guide)

### 1. Cores e Paletas
A paleta de cores foi dividida entre cores primárias (marca), tons neutros (Dark/Light) e cores de feedback (Sucesso/Erro).

#### 🍊 Primária (Laranja)

*   **Primário (Base):** `#FF6200`
*   **Primário +1:** `#FF8133`

### 🔤 Tipografia e Escala de Fontes (Font Scale)

A família tipográfica oficial definida para o projeto é a **Poppins**. Os pesos e tamanhos foram configurados para garantir uma boa hierarquia visual:

*   **H1 (Títulos Principais):** 40px
*   **H2:** 34px
*   **H3:** 28px
*   **H4:** 24px
*   **H5:** 18px
*   **Parágrafo (Corpo de Texto):** 16px
*   **Small (Textos de Apoio / Legendas):** 14px

---

### 👁️ Teste de Contraste e Acessibilidade

Para validar a legibilidade e usabilidade da interface em diferentes contextos, foram aplicados três cenários de testes de contraste com fundos específicos:

1.  **Fundo Light (`#D3DDE4`):** Aplicação de textos em escala de cinza e variações da cor laranja para garantir leitura limpa em temas claros.
2.  **Fundo Primário (`#FF6200`):** Validação de elementos e textos contrastando diretamente sobre a cor principal da marca (Uso de tipografia branca/escura conforme WCAG).
3.  **Fundo Dark (`#0B0A0A`):** Aplicação de textos claros e tons de destaque sobre o tema escuro (Dark Mode).
